# Project Instructions

Before modifying this project, read and follow the project skills:

```text
.agents/skills/rakit-project/SKILL.md
```

These skills are the shared project-specific development guidance for all coding agents. They document the Rakit framework structure, the tested PHP 8.2+ application baseline, application conventions, security rules, testing workflow, and verification commands.

Do not assume this project is Laravel. Follow the Rakit conventions documented in the skill. Keep the skill path as the canonical shared source for project rules; tool-specific configuration may reference it but must not silently replace it.
